# Semantic Visualization

Use this workflow when supplied footage alone would produce long static passages, when a faceless format needs visual authorship, or when a reference translates narration into contextual animation.

## Visual Jobs

Assign each narrative beat one primary job before choosing an asset:

- `source-proof`: show the real action, input, output, person, event, or product behavior that substantiates the claim.
- `screen-action`: preserve a continuous software action whose sequence matters.
- `programmatic-ui`: explain a process with authored interface elements, cursors, search states, cards, progress, counters, or windows.
- `generated-context`: turn an abstract situation, metaphor, setting, or emotion into an illustrative image or motion clip.
- `diagram`: clarify sequence, comparison, transformation, hierarchy, or cause and effect.
- `kinetic-type`: emphasize exact wording, correction, deletion, contrast, or a memorable phrase.
- `stock-or-meme`: provide recognizable cultural shorthand or reaction when rights and tone allow it.
- `negative-space`: intentionally reduce information before a reveal or emotional beat.

Do not use motion as a substitute for assigning a job. A zoom, transition, or animated title without a narrative purpose is decoration.

For each material spoken beat, identify the claim/takeaway, concrete visual object or action, evidence role, and source timestamp when required. A generic product screen does not count as coverage merely because it belongs to the named product.

Each foreground animation must answer: "What should the viewer notice now, and which spoken word or action triggered it?" Ground focus boxes, scans, cursors, highlights, and camera moves in the actual rendered media rectangle after crop/scale. Record the target region and activation time in the beat map, verify the active frame, and remove cues that point at no relevant object. Decorative background motion remains subordinate to proof.

## Evidence Hierarchy

Use real source material for product behavior, before-and-after transformations, testimonials, performance claims, and real-world events. Generated visuals may explain what the viewer is seeing, but they cannot prove it happened.

For a transformation claim, preserve the complete evidence chain when practical:

`input or before -> processing or action -> output or after -> next use`

If the actual result contradicts the intended claim, narrow the claim or record a new valid example. Do not edit the result into compliance.

## Asset Routing

- Use existing source footage when it is both truthful and legible.
- Use HyperFrames and GSAP for text, diagrams, UI simulations, progress, cursors, window choreography, and reusable 2D or 2.5D motion.
- Use image generation for a new still, setting, object, recurring motif, or stylized illustration. Animate the still with restrained, parallax, masks, and restrained camera motion when full generated video is unnecessary.
- Use an authorized video-generation system when the beat requires organic motion, a moving character, changing environment, or cinematic action that cannot be built convincingly from layers.
- Use licensed stock or supplied memes when cultural recognition matters more than visual novelty.

Record provenance and generation status in the asset-gap audit and visual beat map. Do not purchase media or spend generation credits without authorization when it has not already been granted.

## Coherence

Define a reusable visual system instead of generating each beat independently. Choose a recurring character, object, interface grammar, texture, palette, camera behavior, or transition motif. Limit style changes to deliberate narrative shifts.

Generated characters require identity references and consistency review across shots. When consistency is weak, prefer a recurring object or graphic motif over a character.

## Rhythm

For feed-first short-form, avoid long runs of unchanged composition. Vary the visual because the narrative job changes, not because a timer elapsed. A useful sequence often alternates proof, explanation, context, and payoff.

Keep claim-bearing UI readable. Full-frame source, selective crops, and short punch-ins usually outperform decorative device frames. Separate captions from active controls and product evidence.

## Review

Before build, verify:

- The first visible frame communicates subject, tension, action, or result.
- Every important sentence has an intentional visual response.
- The core claim is proven with real evidence.
- Generated inserts match the spoken meaning and do not introduce unsupported facts.
- Consecutive beats do not repeat the same composition without a reason.
- Recurring visual elements remain recognizably consistent.
- The visual plan remains legible at phone-feed scale.

After the draft render, review the composition muted and at reduced size. If the story becomes unintelligible without narration, strengthen the visible action and proof before adding more decoration.
