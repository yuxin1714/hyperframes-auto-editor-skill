# Platform Routing

Platform rules and trends change. Check current workspace knowledge and available platform-specific skills when the destination is named. Record the observation date for time-sensitive assumptions.

## Decision Variables

Adapt the edit using the discovery context; expected viewing state; aspect ratio and UI safe zones; target duration; primary success signal; caption and audio behavior; originality, watermark, disclosure, and music-license requirements; and packaging such as cover frame, title, description, keywords, hashtags, and CTA.

## Stable Defaults

These are defaults, not claims about an algorithm:

- Design for the requested native aspect ratio and protect platform UI areas.
- Make the opening understandable without prior context.
- Ensure the first frame and first spoken line make one coherent promise.
- Use captions when speech comprehension would otherwise depend on sound.
- Prefer readable pacing and complete ideas over arbitrary maximum cut frequency.
- Remove captured watermarks and social-app chrome only when a clean source exists and the user has the right to use it.

## Platform Skill Routing

- TikTok: use `viral-tiktok-content` when available.
- Instagram Reels: use `viral-instagram-reels` when available.
- Cross-platform vertical short-form or YouTube Shorts: use `viral-short-form`, then resolve platform-specific packaging separately.
- Use `viral-hooks` for opening alternatives and `viral-captions-and-ctas` for caption and CTA packaging.

Do not copy one platform's visible UI or creator conventions into the video unless the brief calls for that look. Reference screenshots often include app chrome that belongs to the viewing surface rather than the source edit.
